# 동광교회 60주년 기념 온라인 성경퀴즈

동광교회 창립 60주년을 기념하여 제작된 온라인 성경퀴즈 웹 애플리케이션입니다.

|------|------|
| **80문제 퀴즈** | 4권(학개/스가랴/에스라/느헤미야) × 20문제, 객관식 + 주관식 |

## 퀴즈 시스템 상세

### 문제 구성

| 성경 | 문제 수 | 난이도 분포 |
|------|---------|------------|
| 학개 | 20문제 | 하/중/상 혼합 |
| 스가랴 | 20문제 | 하/중/상 혼합 |
| 에스라 | 20문제 | 하/중/상 혼합 |
| 느헤미야 | 20문제 | 하/중/상 혼합 |

- **객관식**: 4지선다, 제한시간 20초
- **주관식**: 텍스트 입력, 제한시간 30초
- **출제 순서**: Fisher-Yates 셔플 알고리즘으로 매 게임마다 랜덤 배치

### 점수 체계

```
기본 점수 = 난이도별 (하: 100 / 중: 200 / 상: 300)
스트릭 보너스 = 연속 정답 수 × 10 (최대 +100)
최종 점수 = 기본 점수 + 스트릭 보너스
```

### 타이머 시스템

- 시각적 프로그레스 바 (CSS transition)
- 색상 변화: 초록(>50%) → 노랑(25~50%) → 빨강(<25%)
- 마지막 3초 펄스 애니메이션

## 스마트 정답 판별

주관식 답안을 유연하게 처리하는 한국어 특화 정답 판별 엔진을 구현했습니다.

### 1. 한국어 어미 변형 처리

```
"회복하다" → "회복함", "회복하다" 모두 정답
"무너진다" → "무너짐" 도 정답
```

### 2. 접속사 순서 무관 처리

```
"산발랏과 도비야" = "도비야와 산발랏" ✓
"과/와" 접속사의 앞뒤 순서를 자동으로 교환하여 비교
```

### 3. 쉼표 구분 답안 순서 무관

```
"제금, 비파, 수금" = "수금, 비파, 제금" ✓
쉼표로 구분된 답안의 순서에 관계없이 정답 인정
```

### 4. 약어/숫자 처리

```
"42360명" = "42360" ✓
단위(명, 개 등)의 유무와 관계없이 정답 인정
```

## 게이미피케이션

### 목숨 시스템
- 시작 시 하트 3개 부여
- 오답 또는 시간초과 시 1개 감소
- 0개가 되면 게임오버

### 연속 정답 스트릭
- 2연속부터 보너스 점수 적용
- 3, 5, 7, 10연속 시 특별 오버레이 연출
- 스트릭 카운터 UI 표시

### 기록 경신 시스템
- 게임 시작 시 Firestore에서 이전 최고 기록 로드
- 실시간으로 기록 경신 여부 추적
- "기록 경신 중!" 알림 표시
- 기록에 근접할 때 힌트 메시지 제공

### 라이벌 시스템
- 리더보드 상위 20명의 점수를 실시간 비교
- 특정 플레이어 점수를 추월하면 토스트 알림

### 다이나믹 피드백 메시지
- 정답 시 50개 이상의 랜덤 응원 메시지
- 오답 시 30개 이상의 위로 메시지
- 시간초과 시 15개 이상의 격려 메시지
- 25% 확률로 성경 말씀 인용 (20개)

### 애니메이션 (25+ CSS Keyframes)

| 애니메이션 | 용도 |
|-----------|------|
| `shake` | 오답 시 카드 흔들림 |
| `popIn`, `bounceIn` | 문제 등장 |
| `scoreUp` | 점수 상승 플로터 |
| `streakFire` | 스트릭 밀스톤 |
| `confetti` | 이모지 파티클 (✨🎉⭐💛🎊) |
| `countdownPulse` | 마지막 3초 카운트다운 |
| `celebrateBounce` | 결과 화면 축하 |

## 리더보드 시스템

### 개인 랭킹
- Firestore `scores` 컬렉션에서 상위 20명 조회
- 점수 내림차순 정렬
- 같은 참가자는 최고 점수만 저장 (문서 ID: `그룹_이름`)

### 부서별 대항전
- 부서(그룹)별 합산 점수로 랭킹
- 부서별 참가 인원 수 표시
- 부서 내 최고 개인 점수 표시

### Firestore 스키마

```javascript
// scores 컬렉션
{
  docId: "부서_이름",     // 예: "청년부_홍길동"
  group: "청년부",        // 소속 부서
  name: "홍길동",         // 참가자 이름
  score: 4500,           // 최고 점수
  timestamp: Timestamp   // 기록 시간
}

// feedbacks 컬렉션
{
  docId: auto-generated,
  text: "재밌었습니다!",   // 피드백 내용
  secret: false,         // 비밀글 여부
  createdAt: Timestamp   // 작성 시간
}
```
